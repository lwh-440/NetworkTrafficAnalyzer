# 网络流量分析器

一个基于Python的网络流量分析工具，提供实时网络监控、协议分析和数据可视化功能。

## 功能特性

- 🕸️ 实时网络流量捕获和分析
- 📊 多种协议支持（IPv4/IPv6/TCP/UDP/ARP/DNS等）
- 📈 实时统计和图表展示
- 🔍 详细的报文解析和十六进制查看
- ⚙️ 灵活的过滤器配置
- 💾 数据导出和报告生成
- 📱 友好的图形用户界面

## 系统要求

- Python 3.8+
- Windows/Linux/macOS
- 管理员/root权限（用于网络接口访问）
